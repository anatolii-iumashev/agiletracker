# Product Overview

AgileTracker is a universal work management platform — a Jira/Redmine alternative for teams that want power without complexity.

## What it does

- Track tasks, bugs, and features as **Items**
- Organize items with **Labels** (tags)
- Visualize work on **Kanban boards** with drag-and-drop
- Assign items to users, set dates, track time
- Manage roles and permissions via `spatie/laravel-permission`
- Full activity log on every change via `spatie/laravel-activitylog`

## Use cases

- Agile development (Scrum, Kanban)
- Bug tracking and feature requests
- HR processes (onboarding, leave requests)
- Customer support tickets
- Marketing campaign planning
- General project management

## Target audience

Solo devs, small teams (2–15), and mid-size teams (15–50) — technical, self-hosting, tired of overcomplicated tools.

## Key principles

- Minimal UI, zero bloat
- Open-source (MIT), self-hosted
- Developer-first language
- Jira-level depth without the learning curve
